## 一、待实机

### 元件管理终端：驱动器格式自动兼容 — P2

- ⬜ 验证**ME 箱子不进元件表**：放一台 `ae2:chest`，表中不出现该行。
  - 判据：格序长度与 `getCellCount()` 不等的宿主被排除，显式排除 `IMEChest`。
- ⬜ 验证**错放矩阵遇聚合时整台跳过**：「压缩统一管理」不动 `ae2:drive` 里的 ECO 矩阵。
  - 判据：两张盘一张不少，不出现「写回失败且原件放不回去」日志。
- ⬜ 验证**矩阵上传普通驱动器被拒**：右键上传到 `ae2:drive` 静默拒收，原盘留在矩阵座。
- ⬜ 验证**存量错放仍可取出**：旧存档 `ae2:drive` 里的 ECO 矩阵能取回，取出路径不设格式闸。
- ⬜ 验证**格式闸双向**：AE2 元件进矩阵座被挡，ECO 委派 handler 认领的创意元件两边都能放。
  - 判据：单测 `cellClaimedByBothHandlersGoesEitherWay` 已钉住「两边都认」的口径。
- ⬜ 验证**第三方驱动器**：实现 `IChestOrDrive` 但不继承 `DriveBlockEntity` 的设备照常列出。
  - 判据：优先级读不到显示「—」而非 0；非 `IPriorityHost` 的中键入口报不支持。
- ⬜ 验证**库存长度护栏**：摆一台带输出缓存槽的第三方驱动器，确认该列没列还是不该列。
  - 判据：护栏要求库存长度逐一等于契约格数，长出的合法驱动器会消失而非错位读写。

### ECO 数字奇点物品存储矩阵的大宗按钮 — P2

- ⬜ 验证**三枚按钮三档显隐**：非大宗元件全隐、无压缩链只留「压缩统一管理」、有链三枚都在。
  - 判据：奇点矩阵、旧 MEGA 矩阵、青春版 L1 小宗仓各归其档，截断物钮画选中链那一级。
  - 前置：数字奇点物品存储矩阵需 Bigger AE2 在场才注册。
- ⬜ 验证**聚合归属只按优先级**：高优先级矩阵收满、低优先级只接溢出，库存本身不动。
  - 判据：顺序为矩阵自身元件级 → 控制器 → 扫描序；日志出现 `p?` 即优先级没读到。
- ⬜ 验证**空的高优先级矩阵能接收**：0 标记的矩阵按一次统一管理，链应搬过去而非原地去重。
- ⬜ 验证**优先级来源**：ECO 主机取控制器，AE2 驱动器与 ExtendedAE `ex_drive` 取自身 `getPriority()`。
  - 判据：日志每站点打 `/q<自身>` `/p<宿主>`，`p?` 表示控制器优先级没读到。
- ⬜ 验证**生效截断取上游账本**：`getCompressionCutoff` 与配置槽标记物分歧时首轮写回，核对回执条数。
- ⬜ 验证**归并边界的两种无回执**：`touched == 0` 与名单超格数整份不写分开看。
  - 判据：必要时补「没有需要整理的标记」回执。
- ⬜ 验证**低版本 ECO 的加载拦截**：装 21.2.1–21.2.11 应整包停在加载阶段。
  - 判据：报错屏点名「Mod ae2_pattern_disk only supports neoecoae [21.2.12,)」。
- ⬜ 核对**两处 ECO 契约脆弱面**：名字兜底漏认上游搬树改名、`getCellInventory` 未配对释放。
  - 判据：`ECO_CELL_INTERFACES` 的名字兜底与 `releaseCellInventory` 配对都要复核。

### 闪电科技兼容：三台供应器的实机 — P2

- ⬜ 验证**可选依赖缺席**：不装 `ae2lt` / `ae2ltpp` 时三台设备不注册、模组照常启动。
- ⬜ 验证**在场时的设备入口**：三台方块可放置、可开屏，工具栏按钮与高级设置子页可用。
- ⬜ 验证**磁盘增减同步**：插盘、换盘、编码写入刷新样板列表，抽走磁盘后样板从网络消失。
- ⬜ 验证**拆机与内存卡**：拆机只掉磁盘，内存卡导入导出不产生样板副本。
- ⬜ 验证**9216 槽样板栏**：重建、存档与内存开销。
- ⬜ 验证**过载无线分组**：样板访问终端分组沿用上游逻辑，取最频繁的无线终端组。
- ⬜ 验证**神秘农业封包链路**：灌注祭坛与觉醒祭坛的封包核心加适配卡，跑通一条完整合成。

### AE2 Crystal Science 兼容：谐振与自装配供应器 — P2

- ⬜ 验证**谐振设备 FAST 档抽取**：只把相邻存储的样板输出抽进网络，相邻接口内容不动。
- ⬜ 验证**AECS 缺席与低版本**：未装或低于 1.2.1 时两套设备不注册、模组照常启动。
- ⬜ 验证**面板形态的设置保留**：绑定目标、抽取档、拆下掉落与内存卡设置都在。
- ⬜ 验证**超 32 个输出 key 的轮转**：两轮内靠后 key 能被抽到，记录多 `side` 包装的性能。
- ⬜ 验证**PULL_MODE 接管**：设置路径不再出现它，宿主面清空时父类空 EnumSet 不抛异常。
