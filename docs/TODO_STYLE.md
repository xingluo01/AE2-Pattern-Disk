# 待办表编写规则

本规则只管 `docs/TODO.md` 一份文件。仓库里**只允许一份待办表**：2026-10-02 的 `ccbcadd` 已把根目录 `TODO.md` 归一到 `docs/TODO.md`，2026-10-30 曾误重建一份，2026-11-05 合并后删除。再建第二份一律视为错误，不是分工。

写作口径对齐 `CHANGELOG_STYLE.md`：一行一条、一句短话、只讲事实、不写成因与实现机制。差别是更新日志写「已经发生的变化」，待办表写「还没做完、可以验收的事」。

## 一、这份表是什么

- 下一轮动手的人（人或 AI 代理）的**工作清单**：打开就知道要做什么、什么算做完。
- 一条待办 = 一件能验收的事；做完即删，不勾 `[x]`、不留「已完成」段、不留归档。
- 不是开发日志、设计说明、测试报告、上游资料库，也不是发版清单。

## 二、该写什么

| 类型 | 收什么 | 落在哪一节 |
|---|---|---|
| 实机验证 | 代码已落地、只差上机，写清验什么与通过判据 | 待实机 |
| 功能待办 | 还没做的功能、还没接的适配 | 未开始 |
| 决策待办 | 「要不要做 / 怎么做」尚无结论，写清待定的是什么 | 未开始 |
| 阻塞条件 | 卡在上游或环境的**前置**，只写会影响下一轮做法的 | 对应条的「前置」子行 |
| 暂缓 | 明确不做但留个由头的，只写阻塞本身 | 暂缓 |

一句话判据：**这条描述的「要做的事」现在还没做吗？** 已经做了，或压根不是一件要做的事，就不写。

## 三、不该写什么

- **已完成的工作**：实现细节、改了哪个类、跑了哪些测试与编译、提交记录 → `CHANGELOG.md` 与 git 历史。
- **已完成条目的勾选框** `[x]`、「已修 / 已补 / 本轮已完成」段、归档段落。
- **实现原理与成因复盘**：为什么这么设计、「此前…现在…」对照、方案取舍 → 代码注释或 `ARCHITECTURE.md`。
- **上游资料与外部噪音**：上游源码事实基线、版本变动、第三方模组崩溃、`javap` 结论 → `UPSTREAM_API_REQUESTS.md`、`LOCAL_CLONES.md`。
- **发版动作与对外文案**：哪天把哪条写进 README 或兼容清单 → `RELEASE.md` 与对应交付文档。
- **已放弃的方案与有意不做的取舍** → 对应提交与代码注释（本表开头已声明不列）。
- 单条里塞多件事、把判据写成散文、重复条目。

被删掉的资料不会丢：本表受 git 跟踪，旧版全文用 `git log -p -- docs/TODO.md` 查。

## 四、结构

- 首行标题，随后一段 `>` 引用：本表口径、状态图例、优先级、指向本规则与归档去处。
- 状态分节固定顺序：`## 一、待实机` → `## 二、未开始` → `## 三、暂缓`；出现「进行中」时插在最前并顺延编号。**没内容的小节整节不写**，不留空标题。
- 末尾固定 `## 归档索引`（不带状态编号）：指向 `CHANGELOG.md`、git 历史、`ARCHITECTURE.md`、`UPSTREAM_API_REQUESTS.md`、`RELEASE.md` 与本规则。
- 功能块用 `### <功能名> — P<n>`，P1 最高、P3 最低。**不要**用 `N.` 占位编号或残留的 `8.` / `9.` 数字，标题本身就是标识。
- 功能块按 P 值升序排；同一功能既有实机项又有待补项，按状态拆成两个块，不要混在一块里。

## 五、工作陈述格式（硬约束）

每条主行固定：

```
- ⬜ <动词>**<对象>**：<一句工作陈述>。
```

- **一行一条**：不换行、不套多层子列表；主行与子行各 ≤135 字节（同更新日志口径）。
- **句首是动作动词**：待实机用 `验证` / `确认`；未开始用 `新增` / `补齐` / `支持` / `调整` / `核对`。抹掉首词后句子仍成立。
- **加粗只给被操作的对象**，一条一次，加粗名词短语而非语气词。
- **只讲事实**：不写成因、不写实现机制、不写「此前…现在…」对照、不写副作用、不写「为什么」。
- 标点全角，引号用「」，代码 / 类名 / 文件名 / 键名用反引号；不贴日志、截图、链接。
- 图例：`⬜` = 这一条还没做完，`⏸` = 暂缓。状态由所在小节决定，主行里不要再写状态词。

可选子行（各一行、最多两条）：

```
  - 判据：<什么算通过 / 什么算做完>。
  - 前置：<解除阻塞的条件>。
```

判据只写结果，不写推导；前置只写条件，不写背景。要保留的硬约束一律改写成 `前置` 子行，不另起段落。

**禁止自由前缀**：`- 背景：` / `- 已有证据：` / `- 事实基线：` / `- 来源：` / `- 维护：` / `- 约束：` / `- 对外文案：` 一律不用——它们不是待办，属于第三节该删的内容。
