# ME样板转存器

<BlockImage id="pattern_transferer" scale="8" />

ME样板转存器在 AE2 空白样板与样板磁盘之间双向转移编码样板。

输入端放入编码样板或已含样板的磁盘，目标槽放入要写入的样板磁盘。从磁盘取出样板后，腾出的空白样板退回所连接的 ME 网络。

一张磁盘一次只接受一种样板类型，并拒绝与当前主输出重复的样板。
