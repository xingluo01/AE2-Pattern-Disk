# 过载样板磁盘供应器

<BlockImage id="overloaded_pattern_disk_provider" scale="8" />

一台用样板磁盘当样板来源的<ItemLink id="ae2lt:overloaded_pattern_provider" />。九个磁盘槽，最多 9216 张样板，过载派发路径与闪电科技原版一致。

用一台过载样板供应器加一张 16K 样板磁盘合成。

## 样板怎么进网络

每张磁盘保留自己的类型锁。装满 `ae2lt:overload_pattern` 的磁盘才是这台设备的目标；锁成别的类型的磁盘不会贡献样板，因为过载派发只执行过载样板。磁盘内容会被镜像进供应器自己的样板栏，磁盘一变就重建一次——磁盘始终是样板唯一的存放处。

抽走磁盘，它的样板立刻从网络消失。拆机掉落的是磁盘，不是样板的第二份拷贝。

## 工具栏

左侧工具栏换成闪电科技那一套，本模组的三枚供应器按钮不在这里：

- **阻挡模式**：关闭、普通、同样板。
- **频率绑定**：与原版同一个绑定界面。
- **自动返回**：关闭、自动、弹出。
- **模式**：普通或无线派发。
- **自适应批量**：与原版同一个开关。
- **输入过滤**：只接收这台设备预期的材料。
- **齿轮**：高级设置，含输入过滤与机器并行度。

## 与原版的差异

- 样板容量跟着磁盘走，不是固定的 36 槽，所以翻页控件没有了；界面改为九个磁盘槽。
- 高级设置页只保留输入过滤与机器并行度；无线策略与速度由主屏的模式、频率按钮覆盖。
- 其余部分——派发、无线连接、返还库存、内存卡设置——都来自原版供应器的逻辑。
