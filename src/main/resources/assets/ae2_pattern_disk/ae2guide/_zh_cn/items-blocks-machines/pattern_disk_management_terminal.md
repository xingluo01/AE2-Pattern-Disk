# ME样板磁盘管理终端

<ItemImage id="ae2_pattern_disk:pattern_disk_management_terminal" />

装在网络线缆上的终端，把**整个网络**上的样板磁盘一次铺开：按持有它的机器分组，一张盘从一行开始，行首第一格是磁盘本身，后面 16 格是它里面的样板；装不下的往下续行。它下面带着与[ME样板磁盘编码终端](pattern_disk_encoding_terminal.md)同款的编码区，所以看到哪张盘不对，可以直接就地重编码并写回去。

## 表格

| 位置 | 内容 |
| --- | --- |
| 组头行 | 一台机器（同名容器合并成一行）：图标、名字、磁盘数量 `(n)` |
| 磁盘行 | 第 1 格是磁盘，第 2～17 格是这张盘里的前 16 张样板（按槽位顺序）；装不下的往下续行，续行 17 格全是样板 |

- **搜索**：左下角的搜索框与编码终端同一个口径——按磁盘名，或填 `#` 开头的标记搜索；装 JECH 时名字/标记按拼音与首字母匹配，右键搜索框清空内容。
- **排序**：工具栏上两枚 AE2 排序按钮作用在**盘内的样板**上——「按名称」比格子里那个名字（产物名），「按 mod」先按产物所属 mod 分组，组内再比名字；「按数量」对样板没有可比的东西（一枚样板就是一件），保持盘里的原顺序。箭头按钮翻转正/倒序。
- **附加排序**：按 mod 排序时多出一枚开关（默认开，排在该档位按钮的下一格）。开了它相当于同时开两层：先把去掉数字后名称相同的归为一组（`1k存储元件`与`4k存储元件`同组，`1k存储组件`另成一组），组内再按名字里的**数值**排（`1k < 4k < 16k < 64k < 256k < 1M`、`4 < 16 < 64 < 256 < 1024`，数字后面跟 k/M/G/T/P/E 时按 1024 的幂算）；关掉就退回 AE2 原本的两层（mod → 名字字面序），「16k」又会排到「1k」前面。不按 mod 排时它不出现。同一枚开关也管着编码终端物品网格的按 mod 排序。
- **滚动**：右侧的滚动条（表长了才亮）——拖滑块、鼠标滚轮、点滑块上/下方的轨道翻页；滚轮在整张界面上都能用。
- **剩余槽位**：这台机器还没插盘的槽会列在它那组磁盘后面，一格一行；左下工具栏的「隐藏槽位/显示槽位」可以把它们收成一行（收起时那一行右上角写着它代表多少空槽），或者按槽逐行展开。
- 解不出配方的样板会盖一层红框，和样板编码终端一样。
- **磁盘格的提示**：把鼠标搁在磁盘格上，会弹出与编码终端磁盘列表同一套信息：名字、已用/容量、标记（开了原版高级信息还多一行标记 id），以及这一格上的四种手势。
- 表格列出当前网络上**所有支持样板磁盘的容器**（本模组两个形态的供应器，以及经 API 登记进来的其他机器）——包括一张盘都没插的机器：它能插几个、还剩几个空槽都看得见，插了盘再抽走也不会让这一组消失。搜索框有内容时，没命中磁盘的机器不再列出来（否则一搜就满屏空机器）。
- 组头显示的是**容器贴着的、或它指向的那台机器**的图标与名字（同一套口径与 AE2 样板访问终端一致）；供应器被玩家命名过就显示命名的名字；什么都没挨着、或者贴着好几台不同类型的机器时，显示它自己。**同名容器合并成一行**，所以表格里不再写坐标。

> 本屏没有网络物品栏，所以从背包 **Shift+点击不会把物品送进 ME 网络**（那会让东西从视线里消失、也没地方拿回来），也**不会落进合成格／处理槽**——那些是编码用的格位，只有对着格子点击或从 JEI 拖入才会设值。Shift+左键在背包里只认样板磁盘（存进选中盘所在的容器），其余物品不会被送进网络、也不会落进编码格位（已编码的样板仍照常回到样板编辑槽）。

## 操作

全部作用在「鼠标下的那一格」上：

| 操作 | 效果 |
| --- | --- |
| 左键磁盘 | 把这张盘取到鼠标上（盘里的样板跟着走） |
| Shift + 左键磁盘 | 把这张盘取进背包 |
| 右键磁盘 | 选中它；再右键取消。选中的那张盘就是「编写样板」的写盘目标（首格会描一圈高亮） |
| 右键磁盘（手里拿着工作方块） | 以该工作方块所属的配方类型覆写这张盘的标记 |
| Shift + 右键磁盘 | 以搜索框中的内容覆写标记（搜索框为空则清除标记） |
| 中键磁盘 | 以这张盘标记所属工作方块的名字重命名它 |
| 左键一张样板 | 把它取到鼠标上 |
| Shift + 左键一张样板 | 把它取进背包 |
| 右键一张样板 | 把它填进样板编辑槽（相当于「拿它继续改」） |
| 左键「剩余槽位」格（鼠标上拿着样板磁盘） | 把这张盘放进该容器的空磁盘槽，表与盘内容立即刷新 |
| Shift + 左键背包里的样板磁盘 | 把它存进**当前选中那张盘所在的容器**（先右键选中一张盘；没选中会在聊天栏提醒） |

> 存入时具体落到哪个槽由服务端挑该容器的第一个空槽——客户端的清单可能落后一帧，让客户端报槽位反而容易写错地方。已占用的磁盘格仍是原手势（左键取到鼠标），不做覆盖交换。存成功后动作栏报一句（快速连点不会刷聊天栏）；没有盘可存、容器已满、容器已不在网格上、以及还没选中盘则在聊天栏说清原因。

> 样板是“物化”出来的：从磁盘里取一张样板要消耗 ME 网络里的**一张空白样板**（与样板访问终端取走同一套账），网络里没有就取不出来；把样板写回磁盘时那张空白样板会退回网络。磁盘本身只是件物品，取它不扣空白样板。
> 手里拿着工作方块时，右键是“打标”而不是选中；想选中就把方块先放下（空手、或拿着别的物品都行）。
> 没有标记的盘只参与名称搜索；`#` 标记搜索里它们没有标记可匹配，用搜索框右侧的开关可以让它们一律留下。搜索框为空时不做任何过滤。

## 编码区

下半部分与样板磁盘编码终端同款：模式轮换（合成 / 处理 / 锻造 / 切石）、过滤槽、替换、输出倍乘等按钮都一样，编码结果写进**右键选中的那张盘**；没选盘时，筛选后只剩一张盘就直接写进它。样板编辑槽里已经放着一枚写好的样板时，再点「编写样板」会把它写进选中的磁盘（不再把它清掉）；不过网格里有内容时，编码仍会用新样板顶替编辑槽里已有的那枚（与 AE2 样板编码终端同款）。

## 与编码终端的区别

| | ME样板磁盘编码终端 | ME样板磁盘管理终端 |
| --- | --- | --- |
| 磁盘列表 | 左侧 24×66 的竖列表 | 顶部整片表格，17 格/行，按机器分组 |
| 面板宽度 | 195 | 340 |
| 编码区 | 有 | 有（同款） |

## 注意

- 表格是**只读视图**：它显示磁盘内容，但修改磁盘请走上面那些操作或编码区，直接把样板拖进格子里不会发生任何事。
- 内容是完整显示的：一张盘装得多就多占几行（首行第 0 格是磁盘，之后每行 17 格都是样板），不是截断。
- 表格里的内容来自服务端按需推送，刚放进机器的盘可能有一两帧只显示磁盘本身。
