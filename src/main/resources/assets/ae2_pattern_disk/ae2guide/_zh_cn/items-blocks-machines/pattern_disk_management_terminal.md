# ME样板磁盘管理终端

<ItemImage id="ae2_pattern_disk:pattern_disk_management_terminal" />

装在网络线缆上的终端，把**整个网络**上的样板磁盘一次铺开：按持有它的机器分组，一张盘一行，行首第一格是磁盘本身，后面 16 格是它里面的样板。它下面带着与[ME样板磁盘编码终端](pattern_disk_encoding_terminal.md)同款的编码区，所以看到哪张盘不对，可以直接就地重编码并写回去。

## 表格

| 位置 | 内容 |
| --- | --- |
| 组头行 | 一台机器：图标、名字与坐标、磁盘数量 `(n)`，右端是这一组磁盘的显示/隐藏开关 |
| 磁盘行 | 第 1 格是磁盘，第 2～17 格是这张盘里的样板（按槽位顺序，最多显示 16 张） |

- **搜索**：左下角的搜索框与编码终端同一个口径——按磁盘名，或填 `#` 开头的标记搜索。
- **滚动**：鼠标滚轮。盘内样板超过 16 张时，超出的部分不在这一行里显示（磁盘本身仍是一张盘一行）。
- 解不出配方的样板会盖一层红框，和样板编码终端一样。
- 表格只列出**当前网络**上的磁盘；机器被破坏、被拆掉后它那一组会自己消失。

## 操作

与编码终端完全一致，全部作用在「鼠标下的那一张盘」上：

| 操作 | 效果 |
| --- | --- |
| 左键磁盘 | 把这台终端的编码目标设为它；编码按钮写盘时写进选中的这张 |
| 右键磁盘（手里拿着工作方块） | 以该工作方块所属的配方类型覆写这张盘的标记 |
| Shift + 右键磁盘 | 以搜索框中的内容覆写标记（搜索框为空则清除标记） |
| 中键磁盘 | 以这张盘标记所属工作方块的名字重命名它 |

> 没有标记的盘只参与名称搜索；`#` 标记搜索里它们没有标记可匹配，用搜索框右侧的开关可以让它们一律留下。搜索框为空时不做任何过滤。

## 编码区

下半部分与样板磁盘编码终端同款：模式轮换（合成 / 处理 / 锻造 / 切石）、过滤槽、替换、输出倍乘等按钮都一样，编码结果写进当前选中的磁盘。筛选后只剩一张盘时，「编写样板」会直接写进它。

## 与编码终端的区别

| | ME样板磁盘编码终端 | ME样板磁盘管理终端 |
| --- | --- | --- |
| 磁盘列表 | 左侧 24×66 的竖列表 | 顶部整片表格，17 格/行，按机器分组 |
| 面板宽度 | 195 | 340 |
| 编码区 | 有 | 有（同款） |

## 注意

- 表格是**只读视图**：它显示磁盘内容，但修改磁盘请走上面那些操作或编码区，直接把样板拖进格子里不会发生任何事。
- 一张盘一行，所以一张 1024 容量的盘不会把整个表格撑开——它的内容按行内 16 格截断显示。
- 表格里的内容来自服务端按需推送，刚放进机器的盘可能有一两帧只显示磁盘本身。
