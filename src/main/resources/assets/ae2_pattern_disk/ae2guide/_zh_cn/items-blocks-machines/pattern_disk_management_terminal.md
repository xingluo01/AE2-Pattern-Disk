# ME样板磁盘管理终端

<ItemImage id="pattern_disk_management_terminal" scale="4" />

安装在网络线缆上的终端，把网络中所有样板磁盘集中列出：按持有磁盘的机器分组，一张磁盘占一行，行首第一格是磁盘本身，其后 16 格是磁盘内的样板，超出部分续行显示。终端下方设有与 [ME样板磁盘编码终端](pattern_disk_encoding_terminal.md) 相同的编码区，可就地对任意磁盘重新编码并写回。

## 表格

| 位置 | 内容 |
| --- | --- |
| 组头行 | 一台机器（同名容器合并为一行）：图标、名称、磁盘数量 `(n)` |
| 磁盘行 | 第 1 格为磁盘，第 2～17 格为该磁盘的前 16 张样板（按槽位顺序）；装不下的续行，续行 17 格全部为样板 |

- **搜索**：左下角搜索框与编码终端口径一致：按磁盘名称匹配，或以 `#` 开头的标记匹配；安装 JECH 时名称与标记按拼音、首字母匹配。
- **排序**：工具栏上两枚 AE2 排序按钮作用于盘内样板。「按名称」比较格子显示的名称（产物名）；「按 mod」先按产物所属 mod 分组，组内再比较名称；「按数量」对样板没有可比项，保持磁盘内原有顺序。箭头按钮翻转正序与倒序。
- **附加排序**：按 mod 排序时额外出现一枚开关，作用于盘内样板，排序规则与 [ME样板磁盘编码终端](pattern_disk_encoding_terminal.md) 的同名开关相同。
- **滚动**：表格超出可视范围时可滚动。
- **剩余槽位**：机器尚未插盘的槽列在该组磁盘之后，一格一行。左下工具栏按钮可将它们收成一行（收起时该行标明代表的空槽数量），或按槽逐行展开。
- 无法解析配方的样板盖有红框，与编码终端一致。
- **磁盘格提示**：悬停磁盘格时显示与编码终端磁盘列表相同的信息：名称、已用容量与容量、标记（开启原版高级信息时另显示标记 id），以及该格支持的手势。
- 表格列出当前网络上所有支持样板磁盘的容器，包括本模组两种形态的供应器以及其它模组提供的机器，未插盘的机器同样列出，可显示其槽位总数与剩余空槽数；插入磁盘后再取出不会使该组消失。搜索框有内容时，没有命中磁盘的机器不再列出。
- 组头显示容器所贴附的或所指向的那台机器的图标与名称，口径与 AE2 样板访问终端一致；供应器被玩家命名时显示该名称；未贴附任何机器或同时贴附多台不同类型机器时，显示容器自身。同名容器合并为一行，因此表格中不显示坐标。

> 本界面没有网络物品栏，因此背包中的 **Shift+点击** 不会把物品送入 ME 网络：物品既不会进入网络，也无法取回，同时不会落入合成格或处理槽（这些格位用于编码，只有直接点击格子或从 JEI 拖入才会设值）。背包中的 Shift+左键只处理样板磁盘（存入选中磁盘所在的容器）；已编码的样板仍照常回到样板编辑槽。

## 隐性操作

以下操作在界面上没有提示：

| 操作 | 效果 |
| --- | --- |
| 左键样板格 | 把该样板取到光标上 |
| Shift+左键样板格 | 把该样板取进背包 |
| 右键样板格 | 把该样板填入样板编辑槽，便于继续修改 |
| R / U（指针悬停在样板格上） | 通过配方查看器（JEI、EMI、REI）显示该格主产物的配方 |

样板格显示的是磁盘内样板的主产物，因此 R/U 查询的是主产物配方。仅样板格响应 R/U：磁盘格、空位、组头行以及尚未推送到的内容不响应；无法解析配方的样板不提交，按 R/U 无反应（该格已标红）。磁盘格与空槽格的按键手势见其悬停提示。

补充说明：

- 样板是物化出来的：从磁盘取出一张样板会消耗 ME 网络中的一张空白样板，与样板访问终端取走样板使用同一套记账；网络中没有空白样板时无法取出。把样板写回磁盘时，该空白样板退回网络。磁盘本身是普通物品，取出不消耗空白样板。
- 存入磁盘时自动使用该容器的第一个空槽，已占用的磁盘格不进行覆盖交换。存入成功后动作栏给出提示；没有可存入的磁盘、容器已满、容器已不在网格上或尚未选中磁盘时，在聊天栏说明原因。
- 没有标记的磁盘只参与名称搜索，`#` 搜索中不会出现。搜索框右侧的开关可让它们一律保留。

## 编码区

下半部分与 [ME样板磁盘编码终端](pattern_disk_encoding_terminal.md) 相同，编码结果写入右键选中的磁盘；该磁盘无法接收时，顺位写入同一容器内的其他已插入磁盘（含空盘，被搜索筛掉的也参与顺位）。未选中磁盘时，搜索栏有内容则按表格行序顺位写入。样板编辑槽中已有样板时，再点「编写样板」会把它写入选中的磁盘，不再清空编辑槽；但网格中有内容时，编码仍会用新样板顶替编辑槽中已有的那一张。

## 与编码终端的区别

| | ME样板磁盘编码终端 | ME样板磁盘管理终端 |
| --- | --- | --- |
| 磁盘列表 | 左侧竖列表 | 顶部整片表格，按机器分组 |
| 编码区 | 有 | 有（同款） |

## 注意

- 表格是只读视图：它显示磁盘内容，修改磁盘需使用上述操作或编码区，把样板直接拖入格子不会产生任何效果。
- 内容完整显示：磁盘内样板较多时占用更多行，首行第 0 格为磁盘，此后每行 17 格均为样板，不做截断。
- 表格内容由服务端按需推送，刚放入机器的磁盘可能有一两帧只显示磁盘本身。
