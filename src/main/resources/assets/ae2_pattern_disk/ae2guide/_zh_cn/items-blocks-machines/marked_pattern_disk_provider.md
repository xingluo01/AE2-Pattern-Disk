# 标记式样板磁盘供应器

<Row gap="20">
  <BlockImage id="marked_pattern_disk_provider" scale="8" />
  <ItemImage id="cable_marked_pattern_disk_provider" scale="4" />
</Row>

标记式样板磁盘供应器自己没有磁盘槽。在同一 ME 网络的磁盘已有的标记里选一个或几个，它就把带这些标记的每一张磁盘里的样板提供给自动合成——是那些磁盘的镜像，不是复制。

其余行为与 <ItemLink id="ae2:pattern_provider" /> 相同：向相邻机器推送样板与材料、带物品返回栏、左侧工具栏也是同一套。

## 选标记

候选区是三行七列的按钮。每个按钮显示该标记所属配方类别的工作方块（催化剂）；一个类别对应多种机器时按固定节拍轮换。看起来是一回事的标记会合并成一个候选：`#minecraft:crafting` 与 `#mode:crafting` 共用一个按钮，因为两者都代表合成样板。你自己手写的标记各自独立。

点一下把该标记加进选中集合，再点一下取消——可以同时选中多个，供应器镜像的是这些标记下磁盘的并集。按钮有三种状态：常态、已选中、光标所在。

- **搜索栏**在候选区上方，只筛候选，右键清空，开界面时不抢焦点。装了 JustEnoughCharacters 时中文名可用拼音与首字母搜。
- **显示模式**在「全部标记」与「只显示已选中的标记」之间切换。
- **清空选中标记**要按两下：第一下按钮变红，第二下才真的清空全部选中。点别处则取消这次确认。

一个标记都没选时，这台供应器不暴露任何样板。这是有意的——空着筛选条件去镜像，等于把网络上所有样板复制一遍。

## 它不镜像什么

镜像出来的样板只服务于自动合成：不出现在样板磁盘管理终端或任何磁盘列表里，也取不出来——磁盘仍是样板唯一的存放处。

镜像是给源供应器已经在提供的那批样板多加了一条投递路径，所以同一条配方可能同时挂在两台供应器上。AE2 会在两条路径之间分配投递，这正是「一批磁盘驱动多台机器」的由来；看合成规划的并行度时留意这一点。

## 阻挡与发配

工具栏保留供应器专属的三枚按钮：

- **阻挡模式**——不阻挡、AE2 的阻挡模式、智能阻挡。
- **分配倍增**——标准发配，或带份数上限的智能发配。
- **产物抽取**——不抽取、抽取、快速抽取。

这三项与选中的标记一起写进内存卡，复制一台配置好的供应器再粘贴到别处，整套设置一并还原。粘到没有某一项概念的设备上，那一项安静跳过。

## 面板形态

贴到 ME 线缆上就是面板形态，界面与行为完全一致；默认只朝自己贴附的那一面推，用扳手可改。两种形态共用同一份逻辑、菜单与布局文档。
