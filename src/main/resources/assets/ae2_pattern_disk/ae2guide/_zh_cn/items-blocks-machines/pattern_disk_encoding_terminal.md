# ME样板磁盘编码终端

<ItemImage id="pattern_disk_encoding_terminal" scale="4" />

ME样板磁盘编码终端在 <ItemLink id="ae2:pattern_encoding_terminal" /> 的基础上加入样板磁盘支持。合成、处理、锻造、切石四种模式的界面与操作与后者基本一致（含替换、流体替代与主产物轮换），差异有三处：

- 编码结果写入样板磁盘，而不是交给样板供应器；没有同组磁盘时留在编码槽中。
- 空白样板不需要放入槽中：该槽只显示 ME 网络中的空白样板数量，编码时直接从网络扣除一张，没有时给出提示。
- 处理模式另有倍乘、倍除与同物品合并三个工具，用于缩放配方倍数或合并同种物品的输入槽，倍率见按钮提示。

终端扫描整个 ME 网络上的样板磁盘，选中一张后即可写入，也可查看与整理磁盘内的样板。

## 编码模式与样板输出栏

终端有四个常规编码模式（合成 / 处理 / 锻造 / 切石），以及三个额外模式（高级 / 雕凿 / 过载——装了对应模组的编码器并放进升级槽后才会出现）。

**往样板输出栏里放一枚已编码样板时，终端会切到与它对应的那个模式**，并按那枚样板把编辑区摆好：过载档摊出每行的物品与「输入/输出」，高级档读回每格的面，雕凿档反推出「把谁雕成谁」并把输入与产物选中。放进去就是要接着编辑它，所以不必自己先切模式。

| 样板 | 切到的模式 |
| --- | --- |
| 合成 / 处理 / 锻造 / 切石样板 | 对应的常规模式 |
| 高级处理样板 | 高级 |
| 雕凿样板 | 雕凿 |
| 过载样板 | 过载 |

把样板拿走（或清成空白样板）不会改模式；额外模式对应的编码器不在升级槽里时也不会切过去。

## 磁盘列表

界面下方列出网络上的样板磁盘。没有搜索条件时全部列出，包括没有标记的磁盘。磁盘格支持的按键手势见其悬停提示。

搜索栏有两种筛选方式：

- **直接输入**：按磁盘名称匹配。安装 JECH 后，中文名、拼音与首字母均可匹配。
- **以 `#` 开头**：按磁盘标记匹配。标记记录磁盘所属的工作方块：写入时鼠标上持有工作方块则记录其类别，鼠标上没有时退回记录刚导入配方的类别，两者都没有时不写入。合成、锻造、切石会归一到对应类别名，因此手动编码的磁盘与导入过同类配方的磁盘同名，可一次搜出；处理模式没有唯一类别，手动编码的处理样板盘保留「处理样板」名称，搜索时匹配「处理」。

搜索栏右侧的开关决定无标记磁盘是否显示：关闭时按输入内容过滤，`#` 搜索中无标记磁盘不会出现；打开时无标记磁盘不受搜索过滤，始终留在列表中。

### 排序

物品网格按 mod 排序时多一枚「附加排序」开关（默认开启）：同一个 mod 里，它先看名称里的阶层词，再按去掉数字后的名称分组，组内按名称里的数值排——同一系列的不同容量因此挨在一起，`16k` 也不会跑到 `1k` 前面。阶层表、以及哪些名字参与数值排序，都能在 `config/ae2_pattern_disk-client.toml` 里调（写法见该文件里的注释）；关掉开关就回到 AE2 原有的两层排序（mod → 名称字面序）。

不按 mod 排序时不显示该开关；管理终端中的同一开关作用于盘内样板。

### 写盘结果

每次写盘都会在聊天栏给出结果。成功时说明写入的磁盘；失败时说明原因，例如磁盘已满、已锁定为其它样板类型、磁盘内已有产出相同的配方、样板无法解析出类型、目标磁盘已不在列表中。

**没有目标时不会报错**：搜索栏为空、且没有任何磁盘属于当前那一组时，样板编出来留在编码槽里，不写盘也不提示——那是「没找到目标」，不是写盘失败。把搜索栏填上（哪怕只填一个 `#`）就会按列表顺序尝试写入（见下节）。

### 自动落盘

搜索栏有内容时，点击「编写样板」会把刚编码的样板按列表顺序依次尝试写入，写进第一张能接收的磁盘，省略先编码再点磁盘两步。写入成功后编码槽清空，退回的空白样板按网络→背包→编码槽的顺序落位。

搜索栏为空时，写入**同一组里已存配方最少的那一张磁盘**；那张写不进（满了、类型不符、已有相同产物）就顺位试存量次少的一张。

「同一组」= 这张磁盘属于的那类样板，与你当前编码模式编出的那一类相同。它怎么算：

- **磁盘打过标记** → 按标记认定（标记就是你的组织意图，见上文「以 `#` 开头」）；
- **没打过标记** → 按磁盘固定下来的类型认定（写入过第一枚样板的盘类型就锁定了）；
- 两者都没有（空盘）、或标记是你自定义的任意文本 → 不算同组，不会被自动写入。

标记与类型其实是同一件事的两种写法，所以标着「合成」的盘和锁着合成类型的盘是一组，不会分开。

| 当前模式 | 编出的样板 | 类型锁会锁成 |
|---|---|---|
| 合成 | 合成样板 | `ae2:crafting_pattern` |
| 切石 | 切石样板 | `ae2:stonecutting_pattern` |
| 锻造 | 锻造样板 | `ae2:smithing_table_pattern` |
| 处理 | 处理样板 | `ae2:processing_pattern` |
| 雕凿 | 雕凿样板 | `rechiseledae:chiseling_pattern` |
| 高级 | 高级处理样板 | `advanced_ae:adv_processing_pattern` |
| 过载 | 过载样板 | `ae2lt:overload_pattern` |

**同一组的盘按「已存配方条数」从少到多排**：样板先填最少的那张，填到与下一张持平就轮到下一张——同组的盘会一起被填平，而不是一直往同一张里塞。

**空盘不会参与**：它既没有标记也没有类型锁，不属于任何一组（否则每张空盘都会来抢）。想写进空盘就把它筛出来或右键选中它。

**一张同组的都没有时不会自动写入**，也不提示，样板留在编码槽里——那不是写盘失败，是没找到目标。把搜索栏填上（哪怕只填一个 `#`）就会改按列表顺序顺位尝试。

## 上传到 NEO ECO 计算集群

安装 NEO ECO AE Extension 后，界面右上角出现上传按钮：把编码槽中的样板送入 NEO ECO 计算集群的样板存储，成功后清空编码槽，并按「网络 → 背包 → 编码槽」的顺序补回对方指定的替代物，通常为空白样板。样板只是被搬到总线槽位（网络中已有该样板）时不补回；对方无法给出替代物时样板留在编码槽中，不会丢失。未安装该模组时按钮不显示。
