# ME样板磁盘编码终端

ME样板磁盘编码终端是一块挂在 ME 线缆上的面板，用来把样板磁盘和样板编码结合起来：它扫出整个 ME 网络上所有的样板磁盘，选中一张后即可把当前编码好的样板写进磁盘，或查看、整理磁盘里的样板。

## 编码模式

终端内置合成、处理、锻造和切石四种编码界面，用界面上的模式按钮轮换切换。切换后配方网格、输出区与可用工具都会跟着换一套。

- **合成模式**：3×3 合成表 + 输出，支持替代样板与流体替代开关。
- **处理模式**：多输入、多输出的处理配方，支持次级产物轮换与倍乘/倍除。
- **锻造模式**：模板槽 + 基底槽 + 材料槽的标准锻造配方。
- **切石模式**：单个输入，下方一屏 12 个候选配方（4 列 × 3 行，行间不留空隙），选中哪个就决定输出；候选更多时可滚动。

## 空白样板

编码不再需要手动往槽里放空白样板。界面上的空白样板槽是只读的，显示的是 ME 网络里现有的空白样板数量；点「编写样板」时直接从网络扣一张。网络里没有空白样板时会给出提示，而不是没有反应。

## 处理配方工具

处理模式独有的一组工具，用于微调大规模自动化的配方倍数：

- **主产物轮换**：把主产物换成第一个副产物，循环切换并同步整理产物槽。
- **倍乘 / 倍除**：按比例放大/缩小整个配方的输入与输出。普通点击 ×2（÷2），按住 Shift ×3（÷3）、Ctrl ×5（÷5）、Alt ×10（÷10）。倍除会检查输入与输出都能被整除，不能整除时不做任何改动。
- **同物品合并**：合并处理配方中同种物品的输入槽，减少配方占用的槽位。

## 磁盘列表

界面下方列出网络上的样板磁盘。默认**只列出带标记的磁盘**——标记记录这张盘属于哪一类配方（详见[样板磁盘](pattern_disks.md)）。没有标记的盘不在默认列表里，不管它里面有没有样板（只写盘、从未绑定过标记的盘也在此列）；用搜索栏右侧的开关可以把它们放出来。

### 搜索

搜索栏有两种筛选方式：

- **直接输入**：按磁盘名称匹配。
- **以 `#` 开头**：按磁盘标记匹配。标记记的是「这张盘属于哪台机器」：右键绑定那一刻如果刚从配方查看器导入过配方，记的就是该配方所属的类别；否则记当前的编码模式。合成、锻造、切石会归一到对应的类别名，所以手编的盘和导入过同类配方的盘叫同一个名字、搜一次就能一起找出来；处理模式没有唯一的类别（不同机器各有各的），手编的处理盘保留「处理样板」这个名字，搜的时候直接搜「处理」。

### 显示无标记磁盘

搜索栏右侧的开关决定没有标记的磁盘要不要出现：

- **常态显示**（关闭）：只列有标记的磁盘，无标记的空盘不出现在列表里。
- **强制显示**（打开）：无标记的盘也一并列出，并且不受 `#` 标记搜索约束——它们本来就没有标记可匹配。有标记的盘仍然照常按标记过滤。

### 鼠标操作

磁盘列表上不同按键对应不同动作：

- **左键**：把当前编码的样板写入该磁盘。
- **使用工作方块右键**：用当前配方类型覆写该磁盘的标记（改标记，不改名字）。
- **Shift+右键**：把搜索栏里的内容作为标记写到该磁盘上。搜索栏为空则清除该磁盘的标记。
- **使用工作方块中键**：按该磁盘标记所属的机器名给它重命名。

### 写盘结果

每次写盘都会在聊天栏给出结果。成功会说明写进了哪张盘；失败会说明原因，例如：盘已满、已锁定为其他类型的样板、盘里已有产出相同的配方、这份样板解析不出类型、目标磁盘已不在列表里。

### 编写样板时自动落盘

搜索栏筛完恰好只剩一张磁盘时，点「编写样板」会把刚编好的样板直接写进去，省掉「先编码、再点磁盘」两步。筛选后不止一张（或一张不剩）时，样板留在编码槽里，聊天栏会说明当前列表里有多少张盘。

## 上传到 NEO ECO 计算集群

装有 NEO ECO AE Extension 时，界面右上角会多出一个上传按钮：它把编码槽里的样板直接送进 NEO ECO 计算集群的样板存储，成功后清空编码槽，并按「网络 → 背包 → 编码槽」的顺序补回一张空白样板。没有装该模组时按钮不出现。
