# 高效分子装配室

高效分子装配室是一台八线程并行的分子装配室。它接受由 AE2 样板供应器推送的合成任务，自身不持有样板管理库存。

每个任务被分配到第一个空闲的执行线程。每个线程都拥有一个 3×3 分子装配合成网格、一个输出槽以及独立的进度状态。GUI 暴露八个页面，每个页面对应一个线程。

## 加速卡

本机器最多可放入五张 AE2 加速卡。速度倍率依次为 1.0x、1.3x、1.7x、2.0x、2.5x 与 5.0x。加速卡影响每个线程完成一个任务所需的时间。

## 输出

产物会先被推送到配置好的相邻目标。剩余输出在可能时插入 ME 网络。容器余料通过同一输出路径返回，并在目标满时保持排队。

## 样板供应器配置

将装配室放置在样板磁盘供应器或其他 AE2 样板供应器旁。供应器供应样板与原料，装配室执行任务并返回产物。
