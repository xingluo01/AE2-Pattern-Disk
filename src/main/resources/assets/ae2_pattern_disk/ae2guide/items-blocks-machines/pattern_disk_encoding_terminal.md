# ME样板磁盘编码终端

ME样板磁盘编码终端是一块挂在 ME 线缆上的面板，用来把网络里的样板磁盘和样板编码结合起来。

终端会扫描整个 ME 网络，把所有的样板磁盘列出来。选中一张磁盘后，可以把当前编码好的样板配方写进这张磁盘，也可以查看和整理磁盘里的样板。

## 模式

支持合成、处理、锻造和切石四种编码模式，用界面上的轮换按钮切换。

## 磁盘操作

- 点击列表中的磁盘：把当前编码的样板配方写入该磁盘（类型不匹配或磁盘已满时会被拒绝）
- 潜行右键磁盘：把当前配方的隐藏前缀绑定到该磁盘，并把磁盘改名为该前缀
- 中键磁盘：快速重命名该磁盘
- 界面上方的 mini 搜索栏：按名字快速找到被重命名的磁盘
