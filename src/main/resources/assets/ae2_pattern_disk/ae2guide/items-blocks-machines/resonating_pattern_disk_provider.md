# Resonating Pattern Disk Provider

<Row gap="20">
  <BlockImage id="resonating_pattern_disk_provider" scale="8" />
  <ItemImage id="cable_resonating_pattern_disk_provider" scale="4" />
</Row>

A [pattern disk provider](pattern_disk_provider.md) built on AE2 Crystal Science's
[Resonating Pattern Provider](ae2cs:resonating_pattern_provider.md): the disks supply the patterns, while the
resonant logic keeps its per-input targets and cross-dimensional dispatch.

Nine disk slots, up to 9216 patterns. Use the <ItemLink id="ae2cs:resonating_linker" /> to set the provider's
144 default input targets; those targets survive breaking the device, a memory card and the panel form.

The toolbar keeps the pattern disk extraction button: off, normal and fast. It only extracts the outputs
declared by the installed patterns.
