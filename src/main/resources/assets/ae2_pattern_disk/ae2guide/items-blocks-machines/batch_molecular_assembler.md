# 批处理分子装配室

批处理分子装配室把样板供应器推来的合成任务先缓存在机器内部的**存储元件**里，等一小段时间不再有新原料进来后，再把缓存里能做的配方一次性做完。适合大批量订单：原料攒够一批再做，产物集中送回网络。

## 缓存栏

界面下一排的九个**缓存栏槽位**，可放入任何类型的存储元件（与 ME 驱动器同款过滤）。元件在这里只当作机器私有的缓存：它的内容不会进入 ME 网络，也不能被网络或管道取出；未注册存储 handler 的元件（如空间元件）放入后不提供缓存功能。**机器工作（有缓存的合成任务）时槽位被锁定**，无法放入或取出，避免刷物品。点击「退回缓存」会把元件里的缓存原材料全部退回 ME 网络。

## 样板池

九个**样板磁盘槽**（界面上一排）。所有磁盘上的配方会汇总成机器的共享样板池，并暴露给 ME 自动合成；这些磁盘也会同时出现在**样板管理终端**与**样板磁盘编码终端**的磁盘列表里。只有工作台、锻造台与切石这三类无耗时配方能被这台机器执行，处理类样板会被拒绝。

中间产物不会被机器私自消化：每次加工产出的物品（含容器余料）都照常送回 ME 网络，由合成 CPU 继续调度下一步，以免与 CPU 的记账冲突。若网络一时装不下整组产物，本次消耗的原料会**退回缓存栏**并延后重试，产物不会临时挤占缓存栏。

## 批次等待模式

机器只受**静默时间**驱动：收料期间持续攒批，直到不再有新原料进来（或缓存攒满），再等待选定的静默时长后一口气做完全部积压：

* **标准**：静默 40 tick 后开做；
* **极速**：静默 10 tick 后开做。

积压没有上限，缓存栏能装多少就攒多少（受元件自身容量约束）；缓存攒满时机器会暂停收料，开批清空后自动恢复。吞吐上限由合成 CPU 的加速卡数决定（CPU 每能 3 tick 最多派发「协处理器+1」份样板），机器侧建议配合 CPU 加速卡使用。

## 加速卡

最多装四张 AE2 加速卡，用于增加**工作线程**：初始 1 线程，每张 ×2（最多 4 张 = 16 线程）。

* **单个配方始终单线程**：一个配方的任务逐单顺序执行，不因加速卡而并行放大；
* **链式合成才调度多线程**：订单里存在多个配方（如 A→B 链）时，每个配方的积压各占一条线程并行排水，层数之间无需相互等待；
* 每 tick 总执行量上限 = 128 × 线程数，大订单跨多个 tick 连续排空，避免单 tick 大量存储 IO 造成卡顿。

合成总量始终由下单数量决定，加速卡不改变产物数量。

## 与样板供应器搭配

把它放在样板磁盘供应器或其它 AE2 样板供应器旁边即可：供应器负责送样板与原料，批处理分子装配室负责攒批加工并回送产物。
