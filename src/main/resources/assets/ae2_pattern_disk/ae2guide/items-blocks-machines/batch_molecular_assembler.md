# 批处理分子装配室

批处理分子装配室把样板供应器推来的合成任务先缓存在机器内部的**存储元件**里，等一小段时间不再有新原料进来后，再把缓存里能做的配方一次性做完。适合大批量订单：原料攒够一批再做，产物集中送回网络。

## 缓存元件

九个**存储元件槽**（界面下一排）。元件在这里只当作机器私有的缓存：它的内容不会进入 ME 网络，也不能被网络或管道取出。**机器工作（有缓存的合成任务）时元件被锁定**，无法取出，避免刷物品。点击「退回缓存」会把元件里的缓存原材料全部退回 ME 网络。

## 样板池

九个**样板磁盘槽**（界面上一排）。所有磁盘上的配方会汇总成机器的共享样板池，并暴露给 ME 自动合成；这些磁盘也会同时出现在**样板管理终端**与**样板磁盘编码终端**的磁盘列表里。只有工作台、锻造台与切石这三类无耗时配方能被这台机器执行，处理类样板会被拒绝。

中间产物不会被机器私自消化：每次加工产出的物品（含容器余料）都照常送回 ME 网络，由合成 CPU 继续调度下一步，以免与 CPU 的记账冲突。

## 批次等待模式

批次开始的时机由「积压量或静默时长」决定（二者任一满足即开做），可在界面左侧按钮中切换两档：

* **标准**：排队满 16 单或静默 20 tick 后开做；
* **极速**：排队满 8 单或静默 5 tick 后开做。

持续供料时按积压量凑批，批与批之间不停歇；供料停顿时按静默窗口冲刷掉尾部小批。吞吐上限由合成 CPU 的加速卡数决定（CPU 每能 3 tick 最多派发「协处理器+1」份样板），机器侧建议配合 CPU 加速卡使用。

## 加速卡

最多装三张 AE2 加速卡。每张让机器同时推进的原料输入并发数 +1，不再改变单个配方的加工时长。

## 与样板供应器搭配

把它放在样板磁盘供应器或其它 AE2 样板供应器旁边即可：供应器负责送样板与原料，批处理分子装配室负责攒批加工并回送产物。
